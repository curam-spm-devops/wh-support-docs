Cúram documentation access is changing to better manage access to detailed product materials. For releases dated July 23, 2026 and later, entitled customers can access documentation through Salesforce / S-Drive alongside their software downloads. Documentation for earlier releases can be requested through Merative Support. The public documentation site will continue to provide announcements, prerequisites, and instructions on how to obtain documentation.
